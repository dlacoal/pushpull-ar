실행 방식

안드로이드 태블릿(크롬)은 실제 교실 바닥을 인식해 물체를 세웁니다. 학생이 걸어 다녀도 물체가 그 자리에 있습니다. 아이패드는 카메라 화면 위에 물체를 띄우고, 기기를 돌리면 시점이 따라갑니다. 컴퓨터에서는 3D 교실 연습 화면이 열립니다.

앱 안의 잠금

전체화면으로 바뀌고 뒤로 가기, 길게 누르기, 확대가 막힙니다. 학생이 앱을 벗어나면 횟수가 기록됩니다. 왼쪽 아래 자물쇠를 3초 동안 누르고 비밀번호(처음 값 1234)를 넣으면 교사 메뉴가 열립니다.

홈 버튼까지 막으려면

웹페이지는 홈 버튼과 앱 전환을 막을 수 없어 기기 잠금을 함께 켜야 합니다.

아이패드 · 사용법 유도된 접근

  1. 설정 → 손쉬운 사용 → 사용법 유도된 접근 → 켜기, 암호 설정
  2. 앱을 연 뒤 상단(또는 홈) 버튼을 세 번 눌러 시작
  3. 끝낼 때 다시 세 번 누르고 암호 입력

갤럭시 탭 · 앱 고정

  1. 설정 → 보안 및 개인정보 보호 → 기타 보안 설정 → 앱 고정 켜기
  2. 최근 앱 화면에서 크롬 아이콘 → 이 앱 고정
  3. 풀 때 뒤로 + 최근 앱 버튼을 함께 길게 누르기

    선생님 비밀번호

    👩‍🏫 선생님 메뉴

    👩‍🏫 수업 전에 읽어 주세요

    1. 실행 방식

    안드로이드 태블릿(크롬)은 실제 교실 바닥을 인식해서 물건을 바닥에 세워요. 학생이 걸어 다녀도 물건이 그 자리에 있어요.
    아이패드는 카메라 화면 위에 물건을 띄우고, 기기를 돌리면 시점이 따라 움직이는 방식이에요.

    2. 앱 안의 잠금

    전체화면으로 바뀌고, 뒤로 가기·길게 누르기·확대가 막혀요. 학생이 앱을 벗어나면 횟수가 기록돼요.
    선생님은 왼쪽 위 🔒 를 3초 꾹 누르고 비밀번호(처음엔 1234)를 넣으면 메뉴가 열려요.

    3. 홈 버튼까지 완전히 막으려면 (꼭 함께 켜 주세요)

    웹페이지는 홈 버튼·앱 전환을 스스로 막을 수 없어서, 기기 자체 잠금을 함께 써야 해요.

    아이패드 — 사용법 유도된 접근

    1. 설정 → 손쉬운 사용 → 사용법 유도된 접근 → 켜기, 암호 설정
    2. 이 앱을 연 뒤 상단(또는 홈) 버튼을 세 번 빠르게 누르기 → 시작
    3. 끝낼 때: 다시 세 번 누르고 암호 입력

    안드로이드(갤럭시 탭) — 앱 고정

    1. 설정 → 보안 및 개인정보 보호 → 기타 보안 설정 → 앱 고정 켜기
    2. 최근 앱 화면에서 크롬 아이콘 누르기 → ‘이 앱 고정’
    3. 풀 때: 뒤로 + 최근 앱 버튼을 함께 길게 누르기

    크롬북·웨일북: 학교 관리자 콘솔에서 이 주소를 키오스크 앱으로 지정하면 가장 확실해요.
